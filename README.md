# O·LESA OS releases

Installation images of O·LESA OS. Download them from [Releases](../../releases).

- `olesa-os-zfs-x86_64.iso` is a hybrid UEFI ISO with the full installer (OpenZFS root with encryption). Attach it as an optical drive in VirtualBox or QEMU with EFI enabled, or write it byte for byte to a USB stick. Secure Boot must be off.
- The ISO boots only through UEFI. In VirtualBox, turn on System → Motherboard → Enable EFI before starting the VM.

Each release lists the SHA-256 of its files.
